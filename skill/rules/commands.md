# Client commands

## W1 Claude Code commands
`/context` (see what fills context), `/usage` (limits and activity), `/compact` (summarise; say what to keep), `/clear` (fresh chat after a checkpoint), `/plan` (plan mode), `/mcp` (inspect connectors), `/rename` (label a session), `/doctor`, `/skill-doctor` (skill context cost, where supported), `/tips`.

## W2 Codex commands
`$tips`, `/status` (context and limits), `/compact`, `/plan`, `/model`, `/reasoning`, `/mcp`, `/review` (scoped review). Start a new chat in the client after saving a checkpoint.
