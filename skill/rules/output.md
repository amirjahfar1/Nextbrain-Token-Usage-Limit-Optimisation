# Output style

## O1 No recaps
Do not restate what the diff or tool output already shows. Report changed / checked / not checked.

## O2 Cite, do not paste
Refer to `path:line`. Never paste file contents, logs or long diffs into replies.

## O3 Language
Reply in short Roman Urdu when the owner writes Roman Urdu. Code, comments, docs and commits stay English.
