# Handoff: <task> (<date>)

## 1. Goal
Owner's request in one or two lines, and what "done" means.

## 2. Owner decisions and preferences
Dated bullets. Include what he said NOT to do.

## 3. Why (and rejected options)
Decisions with the reason; options dropped and why.

## 4. Timeline
Numbered steps with commit ids or file names.

## 5. Current state
- Working and verified (say how).
- NOT verified (say so plainly).
- Traps hit.

## 6. Facts and numbers
Measured values only, with source. Mark heuristics as heuristics.

## 7. Files
Changed, local-only, and files to leave alone.

## 8. Commands
Verify, test and rollback commands.

## 9. Open yes-gates and questions
Each with the default and who decides.

## 10. Next exact action
One concrete next step.

## 11. How to start
Which files to read first, which model, language, what not to re-ask.
